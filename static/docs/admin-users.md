## Admin — Utenti

Gestisci gli account degli utenti.

### Creare un utente

Inserisci username, password (minimo 6 caratteri) e ruolo. L'utente potrà accedere immediatamente con le credenziali fornite.

### Ruoli

- **Pilot** — può gestire i propri device e watchlist, vedere la mappa live.
- **Admin** — accesso completo: gestione utenti, watchlist, notifiche e piloti.

### Resettare la password

Clicca **🔑 Reset pwd** nella riga dell'utente e inserisci la nuova password. Non c'è conferma via email: la password è attiva subito.

### Note

Gli utenti non possono autoregistrarsi: solo un admin può creare nuovi account. Non è possibile eliminare un account dalla dashboard — contatta l'amministratore di sistema se necessario.
