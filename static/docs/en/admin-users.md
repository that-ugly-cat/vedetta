## Admin — Users

Manage user accounts.

### Creating a user

Enter a username, password (minimum 6 characters) and role. The user can log in immediately with the provided credentials.

Users can also register themselves from the home page. Use this section to create accounts manually or to change roles and data of existing users.

### Roles

- **Pilot** — can manage their own devices and watchlists, view the live map.
- **Admin** — full access: user management, watchlists, notifications and pilots.

### Resetting a password

Click **🔑 Reset pwd** in the user's row and enter the new password. There is no email confirmation: the password is active immediately.

### Deleting a user

Click **✕** in the user's row. Deletion also removes all devices registered by that user.
