## Admin — Pilots

Manage the members of each watchlist.

### Adding a pilot

Select the watchlist from the menu, then choose a user from the dropdown at the bottom of the table and click **+ Add pilot**. The user must already have a vedetta account.

### Removing a pilot

Click **✕** in the pilot's row. Their account remains active, but their devices will no longer be visible in the watchlist and they will no longer receive notifications for that group.

### Visible devices

The **Device** column shows the devices registered by the user in their profile. If empty, the user has not yet added any devices — remind them to do so from the "My devices" section.

### Roles

The role within the watchlist is currently always **pilot**. Administration permissions are managed at the account level in the Users section.
